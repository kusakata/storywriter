# storywriter

Ollama を使って、既存の小説本文の続きを執筆するスクリプトです。

入力テキストから世界観とプロットを抽出し、指定した数のシーンを本編として書き足します。`--plot-only` を付けると本編は書かず、プロットへこれから書くシーンだけを追加します。外部ライブラリは使わず、Python 3 の標準ライブラリだけで動作します。

## 必要環境

- Python 3.10 以降
- [Ollama](https://ollama.com/) が起動していること
- 使用するモデルが Ollama に入っていること

デフォルトモデルは次の通りです。

```text
hf.co/bartowski/Ateron_Gemma-4-Novelist-Eclipse-31B-GGUF:Q4_K_M
```

未取得の場合は、あらかじめ pull してください。

```bash
ollama pull hf.co/bartowski/Ateron_Gemma-4-Novelist-Eclipse-31B-GGUF:Q4_K_M
ollama serve
```

## 使い方

```bash
python storywriter.py 小説.txt

# 同じファイルを再指定すると、世界観・プロットを再利用して本編に追記する
python storywriter.py 小説.txt
```

デフォルトでは 3 シーン分の続きを `output/<ファイル名>/本編.txt` に書き出します。

```bash
# 6 シーン書く
python storywriter.py 小説.txt -n 6

# モデルや URL を指定する
python storywriter.py 小説.txt --url http://localhost:11434 --model llama3

# 既存の出力を捨てて最初から生成する
python storywriter.py 小説.txt --fresh

# まいどなニュースを取り込み、新しいプロットに時事ネタを織り込む
python storywriter.py 小説.txt --news

# 本編は書かず、プロットへこれから書くシーンだけを追加する
python storywriter.py 小説.txt --plot-only
python storywriter.py 小説.txt --plot-only -n 6

# 生成テキストと進捗メッセージの表示を抑える
python storywriter.py 小説.txt -q
```

同じ入力ファイルで再実行すると、既存の世界観・プロットを再利用して `本編.txt` に追記します。`--plot-only` の再実行では本編は触らず、`プロット.txt` にこれから書くシーンを足します。やり直したいときだけ `--fresh` を付けてください（`統計.txt` と `prompt/` のログは残ります）。

## 処理の流れ

1. 入力テキストを読み、`output/<ファイル名>/ベース.txt` に保存する
2. `世界観.txt` があれば再利用し、なければ冒頭 2000 字から世界観を抽出する
3. `プロット.txt` があれば再利用し、なければ世界観を使って既出シーンを抽出する。末尾 2000 字から 2000 字ずつ本文を遡り、長さに応じて既出シーン数を増やす。その後「これからのシーン」を 3 つ作る。これからのシーンはベース本文の言い換えにしない
4. 世界観・直近 5 シーン・これから書く 1 シーン・本文末尾 2000 字を渡して本文を 1 シーン書く。本編にはベースの再掲を入れず、新しいシーンだけを書く。分量は約 1000 字が基本で、盛り上がる場面では約 1500 字まで伸ばせる
5. 書いたシーンを `本編.txt` に追記する。モデルの思考タグ（`<|channel>` など）は保存前に取り除く
6. プロットは生成後、整形用プロンプトで「1 行 1 シーン・行内改行なし・日本語」に加工してから保存する
7. 本編が 5 シーン増えるごとに、最近の本編を読んで世界観に必要な追記がないか確認する。全面書き換えはせず、新しい人物・用語・設定など続きに必要な情報だけを足し、全体は約 1000 字に収める
8. 指定シーン数に達するまで繰り返す。プロットの未執筆シーンがなくなったら、世界観と末尾 2000 字と既存プロットから次の 3 シーンを追加する。同じ場面の繰り返しになりそうなら場所や時間を切り替える。`--news` がオンなら、[まいどなニュース](https://maidonanews.jp/) の新着から時事を世界観へ合わせて織り込む
9. `--plot-only` のときは 4〜8 の本編執筆を行わない。初回のプロット作成でこれから書くシーンが 3 つ入るため、追加分は `n - 3`（0 未満なら追加なし）。既存プロットの再利用時は `n` シーン追加する。最後の追加が 3 未満なら、その数だけ作る
10. 実行ごとに `統計.txt` を更新し、AI へ渡したプロンプトを `prompt/` に保存する

## 出力

`output/<入力ファイルの basename>/` に次のファイルが作られます。

| ファイル | 内容 |
|---|---|
| `ベース.txt` | 入力本文のコピー |
| `世界観.txt` | 続きを書くための設定メモ（約 1000 字）。本編 5 シーンごとに必要な情報を追記して更新する |
| `プロット.txt` | 1 行 1 シーン。`[既出]` は入力本文から抽出、`[済]` は本編に書いたシーン、`[未]` はこれから書くシーン |
| `本編.txt` | 生成した本文。同じファイルを再指定すると追記される |
| `統計.txt` | 作成シーン数、処理時間、使用モデルなどの実行記録 |
| `prompt/` | AI に渡したプロンプトの平文ログ（1 回の呼び出しにつき 1 ファイル） |
| `時事.txt` | `--news` 時に取得したまいどなニュースの見出し |

## オプション

| オプション | 説明 | デフォルト |
|---|---|---|
| `input` | 入力テキストファイル（必須） | — |
| `-n`, `--scenes` | 今回作成する本編シーン数。`--plot-only` 時はプロットへ追加するシーン数 | `3` |
| `--url` | Ollama の API URL | `http://localhost:11434` |
| `--model` | 使用するモデル名 | `hf.co/bartowski/Ateron_Gemma-4-Novelist-Eclipse-31B-GGUF:Q4_K_M` |
| `--timeout` | API タイムアウト（秒） | `1800` |
| `--fresh` | 世界観・プロット・本編を削除して最初から生成する。統計とプロンプトログは残す | オフ |
| `--news` | まいどなニュースを取得し、新しいプロットに時事ネタを織り込む | オフ |
| `--plot-only` | 本編は書かず、プロットへこれから書くシーンだけを追加する | オフ |
| `-q`, `--quiet` | 生成テキストと進捗メッセージの表示を抑える。エラーと完了メッセージは出す | オフ |

生成中のトークンは標準エラー出力にストリーム表示されます。`-q` を付けると生成テキストと進捗を出さず、エラーと完了メッセージだけ残します。大きなモデルでは 1 シーンに数分かかることがあります。
