# storywriter

Ollama を使って、既存の小説本文の続きを執筆するスクリプトです。

入力テキストから世界観とプロットを抽出し、指定した数のシーンを本編として書き足します。外部ライブラリは使わず、Python 3 の標準ライブラリだけで動作します。

## 必要環境

- Python 3.10 以降
- [Ollama](https://ollama.com/) が起動していること
- 使用するモデルが Ollama に入っていること

デフォルトモデルは次の通りです。

```text
hf.co/bartowski/Ateron_Gemma-4-Novelist-Eclipse-31B-GGUF:Q4_K_M
```

未取得の場合は、あらかじめ pull してください。

```bash
ollama pull hf.co/bartowski/Ateron_Gemma-4-Novelist-Eclipse-31B-GGUF:Q4_K_M
ollama serve
```

## 使い方

```bash
python storywriter.py 小説.txt
```

デフォルトでは 3 シーン分の続きを `output/<ファイル名>/本編.txt` に書き出します。

```bash
# 6 シーン書く
python storywriter.py 小説.txt -n 6

# モデルや URL を指定する
python storywriter.py 小説.txt --url http://localhost:11434 --model llama3

# 既存の出力を捨てて最初から生成する
python storywriter.py 小説.txt --fresh
```

同じ入力ファイルで再実行すると、既存の世界観・プロット・本編を引き継いで追記します。やり直したいときだけ `--fresh` を付けてください。

## 処理の流れ

1. 入力テキストを読み、`output/<ファイル名>/ベース.txt` に保存する
2. 冒頭 2000 字から世界観（登場人物・口調・舞台・用語など）を抽出し、`世界観.txt` に保存する
3. 末尾 2000 字から「これまでのシーン 3 つ」と「これからのシーン 3 つ」を作り、`プロット.txt` に保存する
4. 世界観・直近 3 シーン・これから書く 1 シーン・本文末尾 2000 字を渡して本文を 1 シーン書く。分量は約 1000 字が基本で、盛り上がる場面では約 1500 字まで伸ばせる
5. 書いたシーンを `本編.txt` に追記する。モデルの思考タグ（`<|channel>` など）は保存前に取り除く
6. プロットは生成後、整形用プロンプトで「1 行 1 シーン・行内改行なし・日本語」に加工してから保存する
7. 本編が 5 シーン増えるごとに、最近の本編を読んで世界観に必要な追記がないか確認する。全面書き換えはせず、新しい人物・用語・設定など続きに必要な情報だけを足し、全体は約 1000 字に収める
8. 指定シーン数に達するまで繰り返す。プロットの未執筆シーンがなくなったら、末尾 2000 字と既存プロットから次の 3 シーンを追加する

## 出力

`output/<入力ファイルの basename>/` に次のファイルが作られます。

| ファイル | 内容 |
|---|---|
| `ベース.txt` | 入力本文のコピー |
| `世界観.txt` | 続きを書くための設定メモ（約 1000 字）。本編 5 シーンごとに必要な情報を追記して更新する |
| `プロット.txt` | 1 行 1 シーン。`[済]` は既出または執筆済み、`[未]` はこれから書くシーン |
| `本編.txt` | 生成した本文 |

## オプション

| オプション | 説明 | デフォルト |
|---|---|---|
| `input` | 入力テキストファイル（必須） | — |
| `-n`, `--scenes` | 今回作成するシーン数 | `3` |
| `--url` | Ollama の API URL | `http://localhost:11434` |
| `--model` | 使用するモデル名 | `hf.co/bartowski/Ateron_Gemma-4-Novelist-Eclipse-31B-GGUF:Q4_K_M` |
| `--timeout` | API タイムアウト（秒） | `1800` |
| `--fresh` | 世界観・プロット・本編を削除して最初から生成する | オフ |

生成中のトークンは標準エラー出力にストリーム表示されます。大きなモデルでは 1 シーンに数分かかることがあります。
